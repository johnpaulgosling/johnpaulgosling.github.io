(Bayesian) Additive Voronoi Tessellations — AddiVortes

Implements the Bayesian Additive Voronoi Tessellation (AddiVortes) model for non-parametric regression and classification. This package allows users to find the model posterior distributions and make subsequent predictions. It is particularly useful for spatial data analysis and complex function approximation where the underlying structure is unknown.

GitHub Package website CRAN

Bayes Linear Kinematics — BayesLinearKinematics

Implementation of Bayes linear (kinematic) adjustments as in Goldstein and Shaw (2004) and Goldstein and Wooff (2006).
